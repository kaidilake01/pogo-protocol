# Security policy

This repository does not claim an independent security audit. Review contracts, configuration authority and dependencies before using them with value.

Do not publish exploit details, private keys or sensitive production data in public issues. If the repository exposes GitHub's **Security → Report a vulnerability** option, use that private channel. Otherwise open a non-sensitive issue requesting a private reporting channel and wait for maintainer contact before sharing details. No private reporting address or bounty program is represented as configured by this document.

Include the affected commit, contract/version, chain, impact and a local reproduction. Keep demonstrations on a local fork or test deployment and avoid interacting with other users' funds.
