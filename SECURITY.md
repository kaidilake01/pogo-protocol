# Security policy

This repository does not claim an independent security audit. Review contracts, configuration authority and dependencies before using them with value.

Report vulnerabilities through [GitHub's private reporting channel](https://github.com/kaidilake01/pogo-protocol/security/advisories/new). Do not publish exploit details, private keys or sensitive production data in public issues. No bounty program is currently offered by this policy.

Include the affected commit, contract/version, chain, impact and a local reproduction. Keep demonstrations on a local fork or test deployment and avoid interacting with other users' funds.
