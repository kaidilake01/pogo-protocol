# Required dependencies

These files support the current contracts in [`../src`](../src). They are retained because the production factory and vault inherit their storage and behavior, current contracts use their types and interfaces, or regression fixtures require them.

Do not select a launch template from this directory. The active template IDs and deployers are listed in [the current deployment snapshot](../../docs/deployments/bsc-mainnet.json).

Superseded release snapshots belong in Git history. Build outputs and deployment journals are excluded from this repository.
